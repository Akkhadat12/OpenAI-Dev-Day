# OpenAI Dev Day — วิธีเปิดบน Windows

งานนำเสนอนี้เป็นไฟล์ในเครื่อง หลังติดตั้ง Python 3 ครั้งเดียวแล้ว ไม่ต้องต่ออินเทอร์เน็ตเพื่อเล่น
ข้อความบนจอเป็นภาษาอังกฤษ บทพูดอยู่คนละไฟล์

## สิ่งที่ต้องมีครั้งเดียว

1. ติดตั้ง Python 3 จาก https://www.python.org/downloads/
2. ตอนติดตั้ง ให้เลือก Add python.exe to PATH
3. ปิดตัวติดตั้งได้เลย ไม่ต้องติดตั้งซ้ำทุกครั้งที่เปิดงาน

## เปิด

1. แตกซิปทั้งก้อนไว้ในโฟลเดอร์ใดก็ได้ ชื่อโฟลเดอร์มีเว้นวรรคหรือภาษาไทยได้
2. ดับเบิลคลิก `START.bat`
3. รอจนเบราว์เซอร์เปิดเอง ที่อยู่จะขึ้นต้นด้วย `http://127.0.0.1:` เท่านั้น
4. ถ้าเซิร์ฟเวอร์ของแพ็กเกจนี้ยังทำงานอยู่ การเปิด `START.bat` ซ้ำจะไม่สร้างเซิร์ฟเวอร์ตัวที่สอง

## ปิด

ดับเบิลคลิก `STOP.bat`
สคริปต์จะปิดเฉพาะโปรเซสของแพ็กเกจนี้ หลังตรวจว่าเป็นเซิร์ฟเวอร์ของงานนี้จริง ไม่ปิดโปรแกรมอื่น

## คีย์บอร์ด

ไม่มีปุ่มบนจอ การคลิกวัตถุไม่จำเป็นต่อการเล่าเรื่อง

- Spacebar: ไปข้างหน้า ถ้าภาพยังเคลื่อนอยู่ การกดจะทำให้จังหวะนั้นไปถึงจุดหมายแล้วค้างไว้ ยังไม่ข้ามฉาก
- R: กลับปกทันที โลโก้ OpenAI แสดงอยู่ตั้งแต่เฟรมแรก บรรทัดชื่อเรื่องยังไม่ขึ้น จนกว่าจะกด Spacebar
- ลูกศรซ้าย: ไปฉากก่อนหน้าในภาพสุดท้ายที่นิ่งแล้ว บนปกปุ่มนี้ไม่ทำอะไร
- F: ขอเข้าหรือออกจากโหมดเต็มจอ ถ้าเบราว์เซอร์ปฏิเสธ จะไม่มีแผงแจ้งเตือนบนจอ
- P: ซ่อนหรือแสดงจุดชี้ของผู้บรรยาย

## จุดชี้

จุดกลมสีฟ้าขนาดเล็กตามตำแหน่งเมาส์ เฉพาะขณะเมาส์อยู่ในกรอบภาพ
ไม่มีทางลาก ไม่มีจังหวะกระพริบ และไม่กดคลิกแทนผู้ใช้
เมื่อเมาส์ออกจากกรอบภาพ เคอร์เซอร์ปกติกลับมา
การใช้แป้นพิมพ์อย่างเดียวไม่ต้องมีจุดชี้

## บันทึกหน้าจอ

กด F เพื่อเต็มจอ แล้วรอให้แถบแจ้งของเบราว์เซอร์หายเองก่อนบันทึก
แอปนี้ปิดข้อความของเบราว์เซอร์ไม่ได้

## ถ้าเปิดไม่ได้

- ขึ้นว่าไม่พบ Python: ติดตั้งตามด้านบน แล้วเปิด `START.bat` ใหม่
- พอร์ตถูกใช้: ตัวช่วยจะเลือกพอร์ตถัดไปบน `127.0.0.1` เอง
- หน้าไม่ขึ้น: ปิดด้วย `STOP.bat` แล้วเปิด `START.bat` ใหม่
- ฟอนต์และโลโก้ถูกใส่มาในแพ็กเกจแล้ว ไม่ต้องดาวน์โหลดตอนเล่น
