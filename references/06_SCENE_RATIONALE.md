## วิธีซ้อม

เปิดชุดที่แตกจาก ZIP แล้วใช้เบราว์เซอร์บนเครื่องตัวเองเท่านั้น

- Spacebar คือทางเดินหน้าทั้งหมด ถ้าระหว่างภาพยังขยับอยู่ การกดครั้งนั้นจะให้ภาพปัจจุบันนิ่งก่อน ไม่ข้ามจังหวะ
- R จากทุกฉาก รวมฉากปก ยกเลิกการเคลื่อนไหวแล้วกลับไปภาพแรกของปกทันที โลโก้ทึบ บรรทัดชื่อยังไม่ขึ้น
- ลูกศรซ้ายไปฉากก่อนหน้าในสภาพค้างสุดท้าย ไม่เล่นซ้ำ บนฉากปกไม่ทำอะไร
- F ขอเต็มจอหรือออกจากเต็มจอ ถ้าเบราว์เซอร์ปฏิเสธ จะไม่มีแผงแจ้งบนจอ
- P เปิดหรือปิดจุดชี้ของผู้บรรยาย จุดนี้ไม่ใช่ปุ่มบนจอ
- จุดชี้เป็นวงกลมสีฟ้าอมเขียว ขอบเข้ม มองเห็นเมื่อตัวชี้เมาส์อยู่ในการ์ดเรื่อง ออกนอกการ์ดแล้วจุดหายและเคอร์เซอร์ปกติกลับมา จุดไม่ทิ้งทาง ไม่กะพริบ และไม่บังการคลิก
- บนจอไม่มีเมนู ปุ่ม แถบความคืบหน้า หรือคำใบ้แป้น

## ปกกับภาพที่วาดขึ้น

ฉาก S01 ใช้เวิร์ดมาร์ก OpenAI ปี 2025 จากไฟล์ที่บันทึกที่มาแล้ว สีตัวอักษรของโลโก้เป็นขาวอมเทาบนพื้นเข้ม ไฟล์ต้นทางมาจาก Wikimedia Commons และอ้างอิงหน้าแบรนด์ทางการของ OpenAI การใช้ในที่นี้เป็นการเล่าเรื่องในเครื่อง ไม่ใช่การสปอนเซอร์ ถ้าไฟล์โลโก้ไม่มีเส้นวาด ระบบจะโชว์ดอกบลอสซัมไฟล์สำรองไฟล์เดียว ไม่โชว์ทั้งสองอย่างพร้อมกัน และไม่วาดโลโก้ขึ้นมาแทน

ฉาก S02 ถึง S10 เป็นภาพเรขาคณิตที่วาดด้วยโค้ดบนจอ ไม่ใช่ภาพสารคดีที่สร้างขึ้น ไม่มีโลโก้พันธมิตร และไม่มีกราฟ

## S01

เรื่องที่พูด: นี่คือ OpenAI DevDay 2025 และเป็นจอที่ปุ่ม R ต้องกลับมาทุกครั้ง
ภาพจริง: เวิร์ดมาร์กทึบตั้งแต่เฟรมแรก แล้วบรรทัด OpenAI DevDay 2025 ค่อยปรากฏใต้โลโก้
ทำไมช่วย: ปักหมุดชื่องานโดยไม่ต้องพึ่งคำโฆษณา
จังหวะ: เข้าทันทีที่โลโก้ แล้วเผยชื่อ ค้างไว้ได้
สิ่งที่ไม่โชว์: จำนวนผู้ร่วมงาน หรือคำโปรยงาน
ความไม่แน่นอน: ไม่ได้ทดสอบตัวเปิดบน Windows

## S02

เรื่องที่พูด: ซอฟต์แวร์กำลังถูกวางให้วิ่งในการสนทนา
ภาพจริง: กรอบวงเล็บกับแถบเงียบก่อน แล้วประโยคภาษาอังกฤษสั้น ๆ โผล่ทีหลัง
ทำไมช่วย: ให้จำภาพเดียวว่าพื้นผิวคือแชท ไม่ใช่ระบบปฏิบัติการ
จังหวะ: กรอบมาก่อนคำ ค้างเมื่อกรอบและประโยคอยู่ครบ
สิ่งที่ไม่โชว์: ชิปสถานะ และหน้าต่างเดสก์ท็อป

## S03

เรื่องที่พูด: สี่เสาก่อนลงรายละเอียด
ภาพจริง: ชื่อเรื่อง แล้ว Apps, Agents, Codex, Models/API ทีละใบ
ทำไมช่วย: เป็นแผนที่ ไม่ใช่ปุ่มถัดไป จึงไม่มีลูกศร
จังหวะ: เผยทีละใบตามจังหวะ Spacebar แล้วค้างสี่ใบ
สิ่งที่ไม่โชว์: ว่านี่คือกำหนดการทุกเซสชัน วันที่กับเมืองอยู่ในเสียงบรรยาย

## S04

เรื่องที่พูด: Apps SDK อยู่บน MCP และสถานะวันงานคือ Preview
ภาพจริง: การ์ดว่าง แล้ว Apps SDK พร้อมชิปสีอำพันคำว่า Preview จากนั้น MCP และลูกศรเส้นเดียวชี้ลง
ทำไมช่วย: ลูกศรเป็นคำอธิบายความสัมพันธ์ ไม่ใช่ปุ่มกด
จังหวะ: ชิปอำพันค้างไว้พร้อมคำ Preview
สิ่งที่ไม่โชว์: สีเขียว เพราะไดเรกทอรีสาธารณะยังไม่เปิดวันนั้น

## S05

เรื่องที่พูด: เดโมที่จับต้องได้ด้วยชื่อแอป
ภาพจริง: ชื่อ Coursera, Canva, Zillow เป็นตัวอักษร แล้วกรอบด้านในของ Zillow เปลี่ยนจากเล็กเป็นใหญ่
ทำไมช่วย: บอกอินไลน์กับเต็มจอโดยไม่เพิ่มคำ และไม่ดึงโลโก้ที่ยังไม่ตรวจสิทธิ์
จังหวะ: ชื่อทีละราย แล้วขยายกรอบ Zillow
สิ่งที่ไม่โชว์: รายชื่อนี้เป็นตัวอย่าง ไม่ใช่รายชื่อพันธมิตรแบบผูกขาด และไม่ใช่ตัวเลขรายได้

## S06

เรื่องที่พูด: AgentKit เป็นร่มของชุดเครื่องมือ
ภาพจริง: คำว่า AgentKit แล้วส่วนโค้งกับห้าช่องว่าง
ทำไมช่วย: เปิดที่ไว้ให้ฉากถัดไปโดยยังไม่ใส่ชื่อหรือชิป
สิ่งที่ไม่โชว์: การอ้างว่าชุดนี้แก้ทุกปัญหาของเอเจนต์

## S07

เรื่องที่พูด: สถานะของชิ้นส่วนใน AgentKit ไม่เท่ากัน
ภาพจริง: Builder เป็น Beta สีอำพัน, ChatKit กับ Evals เป็น GA สีเขียว, Guardrails มีแค่ชื่อบนชิปสีกลาง, Connectors เป็น Limited beta สีม่วง
ทำไมช่วย: สีไปกับคำ จึงไม่ขายเบตาเป็นของพร้อมใช้
จังหวะ: เผยทีละรายการ แล้วค้างครบ
สิ่งที่ไม่แน่นอน: Guardrails จงใจไม่มีคำสถานะ เพราะเนื้อเรื่องล็อกไว้ว่ามีแค่ชื่อ

## S08

เรื่องที่พูด: Codex เปลี่ยนจาก Preview เป็น GA แล้วมีช่องทางรอบ ๆ
ภาพจริง: การ์ด Codex โชว์ชิป Preview ก่อน แล้วชิปนั้นหายและถูกแทนด้วย GA จากนั้น Slack, SDK, Admin และเชิงอรรถ 10×
ทำไมช่วย: Preview กับ GA ไม่ขึ้นพร้อมกัน ตัวเลข 10× เป็นเชิงอรรถที่ OpenAI รายงานเอง ไม่ได้ทำเป็นกราฟ
สิ่งที่ไม่โชว์: ชุดข้อมูลที่ยังตรวจทานไม่ได้

## S09

เรื่องที่พูด: สามการ์ดคือเชื้อเพลิงฝั่ง API
ภาพจริง: API fuel แล้ว GPT-5 Pro, Sora 2, และการ์ด mini ที่มี −70% กับ −80%
ทำไมช่วย: เปอร์เซ็นต์อยู่บนการ์ดมินิเท่านั้น
สิ่งที่ไม่โชว์: ราคาดอลลาร์ และชิป GA คำว่าเป็นเคลมของผู้ขายอยู่ในเสียงบรรยาย

## S10

เรื่องที่พูด: สามทางให้ลงมือต่อ
ภาพจริง: Platform ก่อน แล้ว Apps พร้อม Preview, Agents โดยไม่มีชิปเดียว, Codex พร้อม GA
ทำไมช่วย: Agents ไม่มีชิปเดียวเพราะสถานะภายในปนกัน
จังหวะ: ค้างที่สามทาง การกด Spacebar บนค้างสุดท้ายไม่เดินต่อและไม่วนลูป R คือทางกลับปก
สิ่งที่ไม่โชว์: ประโยคปิด และไทม์ไลน์รายได้
